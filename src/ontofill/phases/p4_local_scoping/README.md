# Phase 4: Local scoping (per source and objective)

`draft_local_scope` makes one typed inference call to produce a local PRD and a
technical definition document under
`04-local/<source_id>__<objective_id>/`. It writes JSON and review Markdown
with `generated_by` front matter. The TDD can allow only the host of the
discovered objective URL; a model response cannot add domains or target fields.

This walking-skeleton phase does not probe the site or negotiate revisions.
Ontology recommendations remain empty until a captured observation supports
one. A later live backend regenerates documents written by the recorded double.
